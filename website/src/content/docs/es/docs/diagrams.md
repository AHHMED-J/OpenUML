---
title: Tipos de diagrama
description: Los diagramas que OpenUML puede dibujar.
---

| Grupo | Diagramas |
| --- | --- |
| Estructura UML | Clases, objetos, paquetes, componentes, despliegue, estructura compuesta, perfiles |
| Comportamiento UML | Casos de uso, actividad, máquina de estados, secuencia, comunicación, tiempos, vista general de interacción, flujo de información |
| Procesos | IDEF0, diagrama de actividad de roles (RAD) |

Cada tipo de diagrama tiene sus propias herramientas en la Toolbox. Un modelo puede tener diagramas de todos los tipos, y un elemento puede aparecer en varios diagramas.
