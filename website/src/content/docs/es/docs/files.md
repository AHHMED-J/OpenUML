---
title: Archivos (.mdj)
description: 'Cómo guarda OpenUML los modelos: un archivo .mdj de JSON por proyecto, el formato que leen y escriben otras herramientas UML que usan archivos .mdj.'
---

OpenUML guarda cada proyecto en un solo archivo `.mdj`: texto JSON con los elementos del modelo y los diagramas que los muestran. Es el formato que leen y escriben otras herramientas UML que usan archivos `.mdj`, así que los modelos pueden pasar de una a otra.

- Abrir un archivo nunca lo cambia hasta que guardas.
- El trabajo sin guardar se conserva para recuperarlo tras un cierre inesperado.
- Exporta un diagrama como PNG, SVG o PDF, o el modelo completo como un sitio web interactivo sin conexión.
