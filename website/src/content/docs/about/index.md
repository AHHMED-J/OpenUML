OpenUML is a free, open-source modeling tool, released under the [MIT license](https://github.com/AHHMED-J/OpenUML/blob/main/LICENSE). Its source code, issues and releases are on [GitHub](https://github.com/AHHMED-J/OpenUML).

## Clean-room development

OpenUML is an independent project. It is written from behavioral specifications and contains no third-party proprietary code, icons or assets. StarUML is a trademark of MKLab Co., Ltd.; OpenUML is not affiliated with or endorsed by MKLab or any other UML tool vendor.

## Privacy

OpenUML collects no personal data. Its only automatic connection is the check for a new version, which can be turned off in Preferences.

## Contributing

Bug reports and ideas are welcome as [GitHub issues](https://github.com/AHHMED-J/OpenUML/issues). See [CONTRIBUTING.md](https://github.com/AHHMED-J/OpenUML/blob/main/CONTRIBUTING.md) to help with code.
