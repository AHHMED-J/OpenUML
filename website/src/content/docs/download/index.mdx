## First launch

The builds are not code-signed yet, so each system warns the first time you open OpenUML.

- **Windows:** in "Windows protected your PC", click *More info*, then *Run anyway*.
- **macOS:** open the `.dmg`, drag OpenUML to *Applications*, then right-click it and choose *Open* (or *System Settings › Privacy & Security › Open Anyway*). If macOS says the app "is damaged", run `xattr -cr /Applications/OpenUML.app` once in Terminal.
- **Linux:** make the AppImage executable (`chmod +x OpenUML-*.AppImage`) and run it. Without FUSE 2, add `--appimage-extract-and-run`; on Ubuntu 24.04 or later you may also need `--no-sandbox`.

See the [code signing policy](https://github.com/AHHMED-J/OpenUML/blob/main/docs/CODE_SIGNING_POLICY.md).
