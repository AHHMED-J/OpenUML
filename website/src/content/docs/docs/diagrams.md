---
title: Diagram types
description: The diagrams OpenUML can draw.
---

| Group | Diagrams |
| --- | --- |
| UML structure | Class, Object, Package, Component, Deployment, Composite Structure, Profile |
| UML behavior | Use Case, Activity, Statechart, Sequence, Communication, Timing, Interaction Overview, Information Flow |
| Processes | IDEF0, Role Activity Diagram (RAD) |

Each diagram type has its own tools in the Toolbox. One model can hold diagrams of every type, and an element can appear on several diagrams.
