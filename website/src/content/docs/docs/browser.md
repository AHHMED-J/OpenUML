title: OpenUML in your browser
description: Use OpenUML without installing it, in Chrome, Edge, Firefox or Safari.

[Open OpenUML in your browser](/app/). It is the same app as the desktop version, with the same diagrams, tools and file format.

## Your files stay on your computer

Everything runs inside your browser. There is no server and no account: models are never uploaded, and the page only reads and writes the files you choose.

To work with **Open Recent** and to recover unsaved work, the browser keeps the files you opened (or, in Chrome and Edge, permission to reach them) on this computer only. **File › Open Recent › Clear Recent** deletes them. On a shared computer, clear them when you finish, or use a private window.

## Opening and saving files

| Browser | Open | Save |
| --- | --- | --- |
| Chrome, Edge | Pick a `.mdj` file | Saves to that same file (the browser asks for permission once) |
| Firefox, Safari | Pick a `.mdj` file | Downloads the file under the name you choose |

In Firefox and Safari, **Open Recent** reopens the last version you saved in that browser, and auto-save is off (it would download a file every minute). In every browser, unsaved work is kept in the browser and offered back if the tab closes or crashes.

## Shortcuts that change

Browsers keep a few shortcuts for themselves, so the web version uses others:

| Command | Desktop | Browser |
| --- | --- | --- |
| New | Ctrl+N (⌘N) | Ctrl+Alt+N (⌥⌘N) |
| Word Wrap | Ctrl+Shift+W (⇧⌘W) | Ctrl+Alt+Shift+W (⌥⇧⌘W) |
| Suppress Literals | Ctrl+Shift+T (⇧⌘T) | Ctrl+Alt+Shift+T (⌥⇧⌘T) |
| Close Other Diagrams | Ctrl+F4 | Alt+Shift+F4 |

The menus and tooltips always show the keys that work where you are. The menu bar is inside the page: click a menu, or press F10.

## What only the desktop app does

- Open `.mdj` files from the file manager, and show the open file in it.
- Check for new versions (the web version is always the latest).

PDF exports from the browser are high-resolution pictures of each diagram; the desktop app writes them with selectable text.
