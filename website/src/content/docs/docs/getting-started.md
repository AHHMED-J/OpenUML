---
title: Getting started
description: Create your first model in OpenUML.
---

1. [Download](/download/) and install OpenUML.
2. Open it: a new project starts with an empty class diagram.
3. Pick a tool in the **Toolbox** panel and click on the canvas to add an element. Drag from one element to another to connect them.
4. Edit names right on the canvas, and the rest in the **Properties** panel.
5. Save with `Ctrl+S` (`Cmd+S` on a Mac). The project is one `.mdj` file.

To add another diagram, select the model or a package in the **Model Explorer** and choose *Model › Add Diagram* (it is also in the right-click menu). Every command is also in the command palette: `Ctrl+Shift+P` (`Cmd+Shift+P` on a Mac).
