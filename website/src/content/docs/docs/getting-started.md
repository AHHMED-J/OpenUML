---
title: Getting started
description: Create your first model in OpenUML.
---

1. [Download](/download/) and install OpenUML.
2. Open it: a new project holds only **Model** in the **Model Explorer**, with no diagram yet.
3. Click **Add Diagram...** in the middle of the window and pick a type (class, use case, sequence, IDEF0...). The diagram goes into Model.
4. Pick a tool in the **Toolbox** panel and click on the canvas to add an element. Drag from one element to another to connect them.
5. Edit names right on the canvas, and the rest in the **Properties** panel.
6. Save with `Ctrl+S` (`Cmd+S` on a Mac). The project is one `.mdj` file.

Along the way, small tips with an arrow point at the next thing to use. Each shows once; close it with its ✕ or `Esc`, or just do what it says. *Don't show tips again* turns them off, and *Preferences › Help* brings them back.

To add another diagram, select the model or a package in the **Model Explorer** and choose *Model › Add Diagram* (it is also in the right-click menu). Every command is also in the command palette: `Ctrl+Shift+P` (`Cmd+Shift+P` on a Mac).
